# Zen Garden collection

Runtime copies derived from `Zen_Garden_Godot_Art_Pack` (user-supplied, AI-generated). The pack
itself is not in this repository; keep it as the master copy.

- `zen_NN_<name>.png`: 256 x 256 RGBA. Stray fragments from the source sheets removed, trimmed,
  centred and scaled to fill 244 px. Source resolution is about 512 px per symbol.
- `thumbnail.png`: picker preview, tile body + sakura symbol.
- Tile body and back: `assets/tiles/bodies/tile_body_zen_ivory.png`,
  `assets/tiles/backs/tile_back_jade_lotus.png`, 340 x 386, same crop of the pack's 1024 x 1280
  images. Geometry: `data/tile_art/zen_ivory_v1.json`.
